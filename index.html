③ 教学反思

覆盖你提出的三个层面：改进（针对单节课的迭代）、阶段性评价（单元 / 期中过程性反馈）、总结性评价（期末 / 试卷分析）。形成"计划—实施—评价—改进"的闭环。

阶段性评价 = 形成性评价（Formative）：在学习过程中收集证据、及时调整。参考纽约高中档案袋（Portfolio）评估思路。
总结性评价（Summative）：单元 / 期末的学业成就判定，重在诊断与归因，反哺下阶段教学。

REFERENCE SYSTEM

参考教育体系

本工作台模板的设计依据。可在你的模板中标注对应学校的理念标签。

北大附中

走班 · 单元 · PBL · 书院

  • 选课走班 + 导师制，强调学生自主
  • 以单元为单位整体设计，跨课时统筹
  • 项目式学习（PBL）：真实问题驱动、长周期、成果公开
  • 书院制提供多元成长场景
清华附中

核心素养 · 深度学习 · 大单元

  • 以学科核心素养为导向设计目标
  • 深度学习：高阶思维、迁移应用
  • 大单元教学，结构化统整内容
  • 注重情境创设与问题解决
纽约高中（美式）

UbD 逆向设计 · 档案袋评估

  • Understanding by Design：结果→评估→活动
  • 形成性评价贯穿全程，及时调整
  • 总结性评价重诊断与归因
  • Portfolio 档案袋：过程性证据集
提示：这些理念已内化到上方模板的字段设计中（如 UbD 三阶段、PBL 驱动性问题、反思三层面），你无需手动套用，直接填写即可。
