LECTURE 01

水循环

必修一 · 第三章第一节 水循环 —— 自然界的水是怎样"跑"起来的

课标要求理解水循环的环节与类型；说明水循环对地理环境及人类活动的影响
教材对应人教版必修一 P24–31｜鲁教版必修一 第一单元第2节｜湘教版必修一 第二章第1节｜中图版必修一 第二章
建议课时1 课时（45 分钟）＋1 课时活动
素养指向综合思维（要素联系）、人地协调观（人类活动影响）

一、核心知识点

概念自然界的水在地理环境各要素之间进行连续、循环运动的过程。关键词：连续性、循环性。
主要环节蒸发（＋植物蒸腾）→ 水汽输送 → 降水 → 径流（地表径流／地下径流）→ 下渗 → 回到海洋或陆地。
三种类型海陆间循环、陆地内循环、海上内循环。按水循环发生的空间范围划分。
核心类型海陆间循环是最重要的类型，它使陆地水得到不断更新，是塑造陆地水体的基本循环。

二、三种水循环类型对比（高频考点）

类型发生范围主要环节地理意义
海陆间循环海洋 ↔ 陆地蒸发 → 水汽输送 → 降水 → 径流回海最重要；更新陆地淡水资源；塑造陆地地貌
陆地内循环陆地内部蒸发/蒸腾 → 降水 → 径流更新陆地局部水资源，量小
海上内循环海洋上蒸发 → 降水为海上降水提供水汽来源，量最小
判别口诀：看水汽从哪里来、到哪里去。从海到陆 → 海陆间；陆到陆 → 陆地内；海到海 → 海上内。

三、水循环的地理意义（五条）

  1. 维持全球水量动态平衡——使全球水量在时间上分布不均，但在空间上保持相对平衡。
  2. 更新（再生）淡水资源——全球每年约有 1/3 的淡水资源由水循环更新更新再生的水量约占全球淡水的 1/3。
  3. 调节水热平衡——海洋与陆地之间、大陆与海洋之间热量的传递，缓解了干湿差异。
  4. 塑造地表形态——外力作用中最活跃的动力，侵蚀与搬运，造就 V 形谷、冲积扇、三角洲、喀斯特地貌等。
  5. 实现物质迁移——把地表物质、大气污染物带入海洋，使水圈、大气圈、岩石圈、生物圈之间联系起来。

四、影响水循环的因素与人类活动

自然因素海陆位置、大气环流、地形（坡度影响下渗与径流）、植被覆盖（涵养水源）、气候。
人类活动——修水库改变地表径流季节分配，洪水期削峰、枯水期补水；下游地下水位上升。
人类活动——跨流域调水如南水北调，人为塑造新的水汽输送路径，改变的是地表径流环节。
人类活动——植树造林增加下渗、涵养水源、延缓汇流时间，相当于"给水循环装上缓冲垫"。
人类活动——城市硬化地面不透水 → 下渗减少 → 地表径流激增 → 洪涝加剧与地下水补给减少（雨洪洪涝的直接原因）。
人类活动——海绵城市透水铺装 + 雨水花园 + 地下调蓄池，把"快排"改为"慢排"，回归自然水循环规律。
高频设问："城市建设对水循环的影响"——请分环节作答：蒸发（下渗减少、蒸发略减）、降水（基本不变）、径流（地表径流增加、季节分配变不均）、下渗（减少）、地下径流（减少）。分环节是得分关键，不要只答"影响水循环"。

五、板书设计

水循环（板书）
海陆间循环（最重要）
：海洋蒸发 → 水汽输送 → 陆地降水 → 地表/地下径流 → 回海
陆地内循环：陆地蒸发蒸腾 → 陆地降水 → 径流（量小）
海上内循环：海洋蒸发 → 海洋降水（量最小）
—— 意义：动态平衡 · 更新淡水 · 调节水热 · 塑造地貌 · 迁移物质
—— 人类活动：水库 / 调水 / 森林 / 硬化 / 海绵城市 → 改的是"径流"与"下渗"

LECTURE 02

大气环流与气候

必修一 · 第二章 + 第三章 大气环流与气候 —— 看不见的"空气传送带"

课标要求解释热力环流与大气的水平运动；说明三圈环流的形成；理解气压带风带对气候的影响；分析常见天气系统
教材对应人教版必修一 P33–48｜鲁教版必修一 第二单元第1节｜湘教版必修一 第二章第2–3节｜中图版必修一 第三章
建议课时2 课时（环流 1 课时＋天气系统 1 课时）
素养指向综合思维、区域认知（理想状态气压带风带图）

一、热力环流：所有大气运动的"母题"

形成过程（4 步链）地面冷热不均 → 空气垂直运动（热上升、冷下沉）→ 等压面弯曲 → 同一水平面出现气压差异 → 空气水平运动（风）
等压面规律近地面热处 → 等压面上凸、气压低；近地面冷处 → 等压面下凹、气压高；高空则相反。
规模大尺度：热力环流、三圈环流；小尺度：城市风、山谷风、森林风、湖陆风。
风向判读近地面风由高压指向低压，并受地转偏向力右偏（北半球）→ 形成斜吹。
易错提醒：近地面与高空气压性质相反（近地热低压，高空热高压），这是学生最常错的地方，画图时务必标清箭头。

二、三圈环流的形成（成因逻辑要讲透）

环流圈形成原因近地面气压带近地面风带
赤道低压带（0°）热力原因：终年受太阳直射，升温最强低气压带（上升）—
副热带高气压带（30°）动力原因：高空空气堆积、下沉增温高气压带（下沉）信风带
副极地低气压带（60°）极地冷气流 + 来自低纬暖气流相遇抬升低气压带（上升）盛行西风带
极地高气压带（90°）热力原因：终年寒冷，空气收缩下沉高气压带（下沉）极地东风带
一句话抓主线：赤道与极地是热力原因（冷热不均），30° 与 60° 是动力原因（空气堆积／相遇抬升）。口诀："热极地，动副高低"。

三、气压带风带对气候的影响（东亚+西岸是主线）

地中海气候（30°–40° 大陆西岸）夏季受副热带高压控制，炎热干燥；冬季受西风带控制，温和多雨。亚热带夏旱气候是同一种。
温带海洋性气候（40°–60° 大陆西岸）全年受西风带影响，温和多雨，年降水均匀。
亚热带季风气候（25°–35° 大陆东岸）成因：海陆热力性质差异+气压带风带的季节移动。冬受西北季风，夏季受东南季风。
温带季风气候（35°–55° 大陆东岸）仅在亚欧大陆东岸显著（北美因地形阻挡不明显），由海陆热力差异主导。
热带雨林气候赤道低压带全年控制，全年高温多雨。
季节移动气压带风带随太阳直射点季节移动（7 月北移、1 月南移），是地中海气候与季风气候共有的成因之一。
核心设问："为什么同纬度的大陆西岸与东岸气候不同？"——答题模板：西岸受西风带／副热带高压控制 → 海洋性或地中海气候；东岸受季风环流影响 → 季风气候；再补一句成因差异（西岸常年西风，东岸海陆热力差异＋气压带风带季节移动）。

四、常见天气系统

锋面冷暖气团相遇形成。冷锋坡陡、移动快；暖锋坡缓、移动慢。锋面过境时气温、气压、降水均发生变化。
冷锋符号：▲。快进型。降水在锋后，常出现大风、降温、雨雪天气。
暖锋符号：●。缓进型。降水在锋前，多为连续性降水，锋前增温、锋后降温。
准静止锋符号：▲●。江淮准静止锋 → 梅雨；华南准静止锋 → 华南前汛期阴雨；昆明准静止锋 → 贵阳"天无三日晴"。
气旋（低压）中心气压低，空气辐合上升，多阴雨。典型：台风、飓风。
反气旋（高压）中心气压高，空气辐散下沉，多晴朗。典型：亚洲高压（冬季）、副热带高压（夏季）。

五、板书设计

大气环流（板书）
热力环流：冷热不均 → 垂直运动 → 等压面弯曲 → 水平气压梯度力 → 风（近地高→低，高空低→高）
三圈环流：赤道热力上升 → 30° 动力下沉 → 60° 动力上升 → 90° 热力下沉
气压带：赤道低 · 副热高 · 副极低 · 极地高　风带：信风 · 盛行西风 · 极地东风
→ 气候：西岸（地中海 / 海洋性）　东岸（季风）　季节移动 ±5°
→ 天气：冷锋▲（雨在后）　暖锋●（雨在前）　静止锋▲●（梅雨）　气旋雨 · 反气旋晴

LECTURE 03

人口迁移

必修二 · 第一章第一节 人口迁移 —— 人往哪里走，为什么

课标要求说出人口迁移的概念与分类；分析影响人口迁移的因素；说明人口迁移对地理环境的影响
教材对应人教版必修二 P1–12｜鲁教版必修二 第一单元第1节｜湘教版必修二 第一章第1节｜中图版必修二 第一章
建议课时1 课时
素养指向人地协调观（迁移的双向影响）、综合思维

一、概念与分类

概念三要素① 居住地发生变更；② 跨越一定行政区域界线；③ 超过一定时间（通常半年以上）。
按地理范围国际迁移（跨国）、国内迁移（跨省区／城乡之间）。
按性质自发性迁移（迁入地经济吸引，如务工经商）vs 非自发性迁移（政府组织、政策强制，如三峡移民）。
按时间永久性迁移（户籍、长期定居）vs 临时性迁移（季节性、周期性，如"候鸟式"养老、农民工返乡）。

二、影响因素（由主到次）

因素类别具体因素作用
经济因素（最主要、决定性）地区经济发展水平差异；工资与就业机会；资源开发迁入地提供"拉力"，迁出地形成"推力"，经济因素起决定性作用
社会文化因素家庭、婚姻、亲属关系；宗教；民族；战争常造成规模大、突发性迁移
自然环境因素气候、资源、生态环境、灾害影响较小，多为背景性因素
个人因素年龄、性别、职业、受教育程度、个人偏好影响个体迁移选择与方式
推拉理论（图）："推"——迁出地的不利因素（就业难、生态环境恶化、灾害）；"拉"——迁入地的有利因素（高收入、好机会、好环境）；中间障碍——距离、交通、迁移成本、政策限制、个人心理与家庭牵挂。
运用要点：一条迁移往往是"多重推力 + 多重拉力 + 障碍"共同作用的结果，不要只答单一因素。

三、我国人口迁移的历史阶段（时间轴考点）

时期主要流向主要原因
新中国成立初期（~1960s）东部 → 西部（东北、西北、西南）国家有组织开发边疆、支援建设
改革开放后（1980s–1990s）内地 → 沿海；农村 → 城市（民工潮）经济特区开放、区域发展差距拉大
21 世纪以来务工迁移与养老／随迁迁移并存；流向更分散城镇化、老龄化、家庭支持网络

四、影响：双向、分主体（高频设问）

对迁出地 · 有利缓解人地矛盾、减轻环境压力；提高劳动力素质（带回资金、技术、信息）；更新观念；促进对外联系。
对迁出地 · 不利劳动力流失、特别是青壮年与高素质人才外流；加剧老龄化与人口空心化；农业劳动力不足，影响农业生产。
对迁入地 · 有利提供充足而廉价的劳动力；缓解老龄化、补充劳动力；促进经济发展与城市活力；带来技术与观念。
对迁入地 · 不利就业、住房、交通、治安压力加大；公共服务超载；环境压力加大；可能引发社会管理与文化融合问题。
对社会整体促进城市化与经济重心转移；推动文化传播与交融；但需关注留守儿童与空巢老人等社会问题。
易错提醒：迁移的影响不是单向的。同一因素对不同主体作用方向不同：人口老龄化对迁出地是不利，对迁入地反而是缓解。答题时务必先分主体（迁出地／迁入地／社会），再分利弊。

五、板书设计

人口迁移（板书）
概念：居住地变更 · 跨行政界线 · 一定时间
分类：国际／国内　自发性／非自发性　永久性／临时性
因素：经济（决定性）＞ 社会文化 ＞ 自然 ＞ 个人
推拉：推（迁出地不利）＋ 拉（迁入地有利）＋ 中间障碍
→ 迁出地：缓解人地矛盾 / 人才流失 / 老龄化　→ 迁入地：劳动力 / 活力 / 压力与冲突

⚠️ 十条高频失分点
  1. 问"人类活动对水循环的影响"时，只答"影响水循环"，没有分环节（蒸发／降水／径流／下渗）作答。
  2. 判断三圈环流成因时，把 30° 副热带高压说成"热力原因"（应为动力原因）。
  3. 描述热力环流时，把高空也写成"由高压流向低压"（高空由低压流向高压）。
  4. 解释大陆东西岸气候差异时，只答结果不答成因（西风带 vs 季风环流）。
  5. 冷锋、暖锋的降水位置与符号混淆（冷锋▲雨在锋后，暖锋●雨在锋前）。
  6. 把台风的"中心气压低"与"中心气流下沉"混淆——台风是气旋，中心气流上升。
  7. 人口迁移概念只答"搬了家"，漏掉跨行政界线与一定时间两个要素。
  8. 分析迁移影响时不区分迁出地／迁入地主体，把"加剧老龄化"当成迁入地的不利影响。
  9. 答"影响人口迁移的因素"时只写"经济"，未说明推拉机制与中间障碍。
  10. 把临时性／季节性人口流动（如农民工返乡、候鸟式养老）排除在人口迁移之外。
